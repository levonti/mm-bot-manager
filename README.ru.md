# mm-bot-manager

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md)

Бот Mattermost для управления собственными ботами через сообщения: создание,
изменение атрибутов, импорт, выпуск и отзыв токенов. Метаданные и владельцы
хранятся в SQLite или PostgreSQL. Доступ ограничен владельцем и назначенными ролями.

- [Руководство пользователя](docs/ru/user-guide.md)
- [Установка и эксплуатация](docs/ru/operations.md)
- [Разработка и переводы](docs/ru/development.md)

Для первого запуска нужны сервер Mattermost, отдельный бот-менеджер и личный
токен администратора. Установите `MM_DEFAULT_LANGUAGE=ru`. После запуска отправьте
боту `!language ru`, затем `!help`. Предпочтение сохраняется индивидуально.
`!language auto` использует язык профиля Mattermost; неизвестный язык заменяется
на настроенный язык сервера. При отсутствии перевода используется английский.

Команды и параметры одинаковы на всех языках. Пользовательские данные не переводятся.
Язык интерфейса не определяет часовой пояс: задайте `MM_DISPLAY_TIMEZONE` отдельно.
Подробные параметры конфигурации и исторические отчёты доступны через
[английский справочник](README.md). Отчёты фиксируют прошлые проверки, а не текущее
состояние установки.
