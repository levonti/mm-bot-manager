# Руководство пользователя

[English](../en/user-guide.md) · [Русский](user-guide.md) · [Deutsch](../de/user-guide.md)

Отправьте менеджеру личное сообщение: `!language ru`, затем `!help`. Доступны
`en`, `ru`, `de`, `auto`. Ручной выбор приоритетнее языка профиля Mattermost.
Auto использует профиль, затем MM_DEFAULT_LANGUAGE; изменение профиля может
отображаться с задержкой до пяти минут. Повторный выбор auto обновляет профиль сразу.
Часовой пояс настраивается отдельно от языка.

## Боты и токены

Создание: `!create example-bot --repo https://example.com/team/project --criticality 2`.
Заявитель становится владельцем. При настроенных согласующих нужна их проверка.
Имена используют строчные латинские буквы, цифры, точки, подчёркивания и дефисы;
новое имя должно оканчиваться на `-bot`. `!list` показывает ваших ботов,
`!info example-bot` — подробности. Изменить описание:
`!update example-bot --description "Уведомления сервиса"`.
Имя, репозиторий и критичность изменяются после согласования в личных сообщениях.
Смешанная команда ожидает согласования целиком. `!delete example-bot` отключает бота.
Критичность: 1 — критичный, 2 — важный, 3 — вспомогательный.
Отображаемое имя: до 64 Unicode-символов; описание: до 1024.

`!import example-bot --repo https://example.com/team/project --criticality 2` всегда
требует согласования в личных сообщениях. Серверные токены не изменяются.
`!token create example-bot` выдаёт токен в личном сообщении, которое остаётся в истории.
Храните токен в секрете. `!token list example-bot` показывает учтённые ID токенов;
`!token revoke <token_id>` отзывает токен. На сервере могут быть другие токены.

Приложите один PNG/JPEG к `!icon set example-bot` в личном сообщении для изменения
изображения. До 5 MiB, 4096×4096, без анимации. `!icon reset example-bot` возвращает
стандартное изображение; `!avatar` — синоним. Изменять изображение может владелец.

## Роли и обращения

Согласующие используют `!approve <request_id>` или `!deny <request_id> [reason]`
в личных сообщениях; самосогласование запрещено. Читатели каталога используют
`!catalog --format cards` или `!catalog --format table`, фильтры --owner,
--criticality, --search и --page. Привилегированная справка доступна только
соответствующей роли в личных сообщениях.

Если обращения включены: `!feedback new <text>`, список `!feedback list`,
статус `!feedback status FB-1`, история `!feedback show FB-1`, ответ
`!feedback reply FB-1 <text>`. Закрытие: `!feedback close FB-1 <reason>`,
повторное открытие: `!feedback reopen FB-1 <reason>`.
Текст: 1–3000 символов, вложения не поддерживаются. Не отправляйте секреты.
Обработчики используют `!feedback queue`, `!feedback take FB-1`, затем
`!feedback set-status FB-1 waiting <question>` или `resolved <solution>`.
Все ответы видны автору; внутренних заметок нет.
